(devkitARM, libctru, citro2d). Personal learning project.

Folders:
- C:\JumpKing3DS = my workspace
  - src_cs\ = read-only copies of decompiled C# (physics-relevant folders only)
  - src\ = my C++ output
  - test\ = native PC tests (g++ only)
- C:\JumpKingDECOMP = full decompiled Jump King C#. READ-ONLY reference.
  Never list, scan, index, or write to it. If a dependency is missing from
  src_cs, tell me which file/folder you need and I'll copy it. Don't search for it.
